# History of Rally Racing Website (70 Years of Flat Out)

## Project Overview
This website is a multi-page informational guide exploring the 70-year evolution of rally racing, from its 1950s endurance roots to the modern high-tech Hybrid Rally1 era.

## Folder & File Structure
```
project-root/
│
├── index.html         # Homepage (70-year overview & statistics table)
├── origins.html       # Page 2 (Origins & Group B Era + YouTube video embed)
├── modern.html        # Page 3 (Modern WRC, Hybrid tech)
├── styles.css         # Main external CSS stylesheet
└── README.md          # Project layout and documentation
```
